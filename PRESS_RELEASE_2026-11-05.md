# PUDDY Inc. Releases PUDDY SQUISH, a Free Browser Tool That Compresses a File to a Target Size You Name

LOS ANGELES - November 5, 2026 - PUDDY Inc. released PUDDY SQUISH, a free tool by Puddy Studios that compresses a file to a target size the user names, in the browser. It needs no account. It is available at https://squish.puddystudios.com.

The file is never uploaded, and the work runs on the user's device. A GIF, video, audio or PDF job, and an image or SVG job with PDF output, fetches its engine from jsDelivr, which receives the request and never the file.

SQUISH has two modes. TO A SIZE looks for the closest fit under the target. MAX QUALITY is a conversion with no target. Sizes are decimal: 1 MB is 1,000,000 bytes.

SQUISH takes images in JPG, PNG, WEBP and BMP, and returns JPG, PNG, WEBP or PDF. A GIF comes out as GIF, MP4, MOV or MKV. Video in MP4, MOV, MKV, AVI, WEBM and more comes out as MP4, MOV, MKV or GIF. Audio in MP3, WAV, M4A, FLAC and more comes out as MP3 or M4A. A PDF comes out as PDF, JPG, PNG or WEBP, and an SVG as SVG, PNG, JPG, WEBP or PDF.

SQUISH installs as a web app.

SQUISH has limits. A PDF is rebuilt from page images, so its text is no longer selectable. PDF to image takes the first 20 pages, and video to GIF takes the first 30 seconds. Large files are bounded by the device's memory. HEIC and TIFF are not supported.
